# 实质性应标资料

## 提取指引

- **企业证书证明**：通常在资格要求或商务要求章节中，关注营业执照、资质证书、许可证、审计报告等要求
- **拟派人员要求（商务要求项）**：人员/团队类要求按「要求项」提取——岗位、数量要求、资格要求（职称/执业资格/经验年限）、是否必需
- **业绩与车辆要求（商务要求项）**：业绩按「年限/数量/类型/金额」要求提取；车辆/设备按「功能/数量/用途」要求提取
- **书面承诺/声明**：通常在投标文件格式或专门的承诺书章节中
- **信用平台查询截图**：通常在资格要求或投标人须知中，关注信用中国、裁判文书网等平台要求
- **厂商授权/检测报告**：通常在技术要求或商务要求章节中
- **公开联系信息**：采购单位/代理机构/联系人/电话/邮箱属公开信息，必须原样提取、不脱敏（见基础信息模板）。
- **通用约定（复选框/符号不可辨）**：原文勾选项或特殊符号（√/×/☑/□/☐/■ 等）在转换稿中丢失、无法判断时，值写「见冲突」或「不可辨」并标注原文位置（章节/条款号），同时列入文末「需用户补充」；**不得替用户勾选**。
- **通用约定（内部矛盾不裁决）**：同一事项多处表述不一致时，按原文分别摘录并标注位置（如「A 处写 X；B 处写 Y」），值写「见冲突」，列入「需用户补充」，**不得自行择一**。
- **通用约定（缺失值）**：原文确无 →「未提及」；项目情形不涉及 →「不适用」（备注写理由）；不得留空，不得写 无/待定/TBD/-/略。

## 提取清单

|  序号 |             提取项             |                      识别指引                     |
| :-: | :-------------------------: | :-------------------------------------------: |
|  1  |            企业证书证明           |      需提供的证照/资质/财务/纳税/审计等资料名称与要求      |
|  2  |        拟派人员要求（商务要求项）      |    岗位、数量要求、资格要求（职称/执业资格/经验年限）、是否必需    |
|  3  |      业绩与车辆要求（商务要求项）      | 业绩年限/数量/类型/金额要求；车辆/设备功能/数量/用途要求 |
|  4  |           书面承诺/声明           |              明确要求投标人提供承诺函/声明函的要求              |
|  5  |          各信用平台查询截图          |          如：需提供信用中国、裁判文书网等平台的查询截图等的要求          |
|  6  | 产品/服务厂商授权、第三方检测报告、其它资质证明资料等 |          如：某些产品需要厂商授权、第三方机构的检测报告等的要求          |
|  7  |          其它实质性应标资料          |              与实质性响应相关的其他资料要求              |

## 输出示例

> 示例标题不带编号：导出脚本会自动生成多级编号（第一章 / 1.1 / 1.1.1 …），提取结果不要硬编码「一、二、1.1」等编号。

```markdown

| 企业资质证书 | 是 | 电子与智能化工程专业承包二级及以上资质证书复印件 | 资质等级符合要求 |
| 安全生产许可证 | 是 | 有效的安全生产许可证复印件 | 在有效期内 |
| 年度财务审计报告 | 是 | 近三年经审计的财务报告 | 近三年 |
| 类似业绩证明 | 是 | 近三年完成的至少 3 个类似项目的中标通知书、合同及验收证明 | 材料名称级 |

| 技术负责人 | 1 人 | 高级工程师职称；8 年以上类似项目技术管理经验 | 是 | — |
| 驻场运维人员 | 8 人 | 具有信息技术类证书；熟悉智慧交通系统运维 | 是 | 驻场配置按原文 |
| 其他技术人员 | 不少于 5 人 | 相关专业证书及类似项目经验 | 否 | — |

| 设备要求 | 电脑等维修设备，按原文功能要求配置 | 是 | 配置要求按原文 |

| 保密承诺函 | 否 | 承诺对招标文件内容保密 | |

| 平台名称 | 是否必需 | 查询要求 | 截图时间要求 |

|----------|----------|----------|------|
| （按项目实际填写） | 是/否 | 只写资料名称与要求级信息 | — |

**需用户补充：** 原文复选框/符号不可辨或同一事项多处表述不一致时，按「见冲突/不可辨」记录并在此列明原文位置与待确认项；原文确无的信息写「未提及」，项目情形不涉及的写「不适用」。
```

# BidGenie libexec 依赖锁定（PRD 附录 B.3）
#
# 安装位置：`plugin/pylibs/`（插件自有目录，**不修改 DSH bundled python 的 site-packages**）
#   PYTHON -m pip install --target plugin/pylibs -r plugin/libexec/requirements.txt
#
# ⚠️ pymupdf4llm 特殊说明（M3 实测，见 docs/acceptance/M3/convert.md）：
#   PyMuPDF 1.24.14 以发行名 `PyMuPDF` 提供 `fitz` + `pymupdf` 两个模块别名；
#   pymupdf4llm 0.0.17 的元数据声明 `Requires-Dist: pymupdf>=1.24.10`，pip 会把它解析成
#   发行名 `pymupdf`（1.28.x，双版本文件冲突）。因此本文件安装后需再执行一次：
#     PYTHON -m pip install --target plugin/pylibs --no-deps pymupdf4llm==0.0.17
#   直接 `pip install -r` 全量安装可能引入 pymupdf 1.28.x，不推荐（除非已按上面两步复核）。
#

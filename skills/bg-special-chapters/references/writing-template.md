# 特殊章节写作模板与禁用表述

## 通用模板（约 150–250 字）

```markdown
### 特殊处理说明

本项为招标文件要求的《{材料名}》（来源：{章节/条款}）。按招标要求需{要求摘要}，具体{内容/参数/偏离项}需用户确认。

**招标要求**

- {原文 1}（来源：{sourceRef}）
- {原文 2}（来源：{sourceRef}）

**处理方式**

原因：本项所需的{证明材料/具体参数}需由用户提供并核对，方案不代为承诺、不编造。
请用户按招标文件要求补充；本方案只保留要求说明与配合方式。

**请用户补充**

- {材料名}：{需要用户提供什么}
- 确认事项：{需要用户确认什么}
```

## 分类型示例

### certificate / test_report

```markdown
本项要求提供所投产品的第三方检测报告（来源：第九章技术要求）。检测结论与报告编号需由用户提供并核对，方案不代为填写。

**招标要求**

- 提供所投产品由第三方检测机构出具的检测报告。

**处理方式**

本项所需检测报告由用户提供，方案只说明配合方式，不承诺检测结论、不编造报告编号。

**请用户补充**

- 检测报告：请提供报告扫描件及编号。
- 确认事项：请确认所投型号与报告一致。
```

### deviation_table

```markdown
本项要求按第六章格式填写《技术、服务偏离表》（来源：第六章响应文件格式）。具体偏离项需由用户确认，方案不代为承诺。

**招标要求**

- 按第六章格式填写技术、服务偏离表。

**处理方式**

本项由用户按格式填写并确认偏离项，方案只保留要求说明与配合方式。

**请用户补充**

- 偏离表：请按第六章格式填写。
- 确认事项：请逐项确认偏离/无偏离。
```

### sample / demonstration

```markdown
本项要求提供样品/现场演示（来源：…）。样品与演示内容需由用户准备，方案只写配合流程。

**招标要求**

- 按招标文件要求提供样品并完成现场演示。

**处理方式**

本项所需样品、场地与演示人员由用户准备，方案只说明配合流程与时间安排，不代做样品。

**请用户补充**

- 样品/演示：请确认样品清单、演示内容与到场人员。
- 确认事项：请确认演示时间与地点。
```

## 禁用表述

| 禁用 | 改为 |
|---|---|
| 我方已具备/已提供/已通过 | 本项所需材料由用户提供并核对 |
| 证书编号：XXX | 证书编号请用户补充 |
| 检测结论：合格 | 检测结论以用户提供的报告为准 |
| 业绩金额：XX 万元 | 业绩金额请用户核对 |
| 人员姓名：XXX | 人员名单请用户确认 |
| 不响应/不满足 | 不在方案中代填，请用户补充 |
| 详见第 X 章 / 见商务部分 | 写明具体来源文件名/条款；不要跨章引用 |

## 章节结果

```json
{
  "chapterId": "2-3",
  "filePath": "chapters/2-…/2-3-技术、服务偏离表.md",
  "status": "done",
  "wordCount": 180,
  "summary": "说明招标要求的技术偏离表/检测报告，明确由用户提供并确认；方案只保留配合方式，不代填、不承诺。",
  "criterionRefs": ["CR-02"],
  "figures": [],
  "tables": [],
  "issues": [],
  "questions": [],
  "blockReason": ""
}
```

- `wordCount` 用审查口径实际字数；不要为凑 200 字灌水。
- `summary` 200–400 字符，写“要求 + 处理方式 + 请用户补充”，不写已具备。
